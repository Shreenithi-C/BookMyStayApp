# BookMyStayApp
# UC6 – Booking History & Reporting

## Overview
Tracks all confirmed reservations for audit, reporting, and customer support.

## Key Features
- Store confirmed reservations
- Support cancellation & review
- Generate reports

## Data Structures
- `List<Reservation>` → ordered storage of confirmed reservations

## Actors
- Admin
- Reporting Service

## Benefits
- Reliable audit trail
- Simplified reporting
- Improved customer support
