# UC3 – Booking Request (FIFO Queue)

## Overview
Introduces a booking queue to handle requests fairly using FIFO principle.

## Key Features
- Accept booking requests
- Enforce arrival order
- Handle high-traffic scenarios

## Data Structures
- 'Queue<Reservation>' (LinkedList)

## Actors
- Guest
- Booking Queue Service

## Benefits
- Predictable booking order
- No race conditions
- Real-world fairness model
