# BookMyStayApp

## Overview
The `dev` branch integrates all six use cases into a complete hotel booking console application.

## Modules
1. **UC1 – Inventory**: Room setup & management
2. **UC2 – Search**: Availability check
3. **UC3 – Booking Queue**: FIFO request handling
4. **UC4 – Confirmation**: Unique room allocation
5. **UC5 – Services**: Add-on service selection
6. **UC6 – History**: Booking history & reporting

## Features
- Modular package structure (`inventory`, `search`, `bookingqueue`, `booking`, `services`, `history`)
- Interactive menu-driven console app
- Real-time inventory sync
- Fair booking order
- Extensible service model
- Complete audit trail

## Benefits
- Scalable architecture
- Clean separation of concerns
- Reliable and fair booking system
- Easy to extend with new features (e.g., payments, user accounts)
